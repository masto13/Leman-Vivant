# Logo · Le monde des vivants

Le symbole « reflet » : les Alpes et leur reflet dans le lac, dans un cercle.
Couleurs : turquoise `#2e7a7b`, brume `#f3f5ef` (fond sombre : `#7cc3bf` sur `#13221f`).
Police du nom : Newsreader (Google Fonts), « vivants » en italique turquoise.

| Fichier | Usage |
|---|---|
| `symbole.svg` | Symbole couleur, vectoriel (impression, documents) |
| `symbole-fond-sombre.svg` | Symbole pour fond sombre |
| `symbole-blanc.svg` | Symbole inversé (sur photo ou fond turquoise) |
| `png/symbole-1024.png`, `png/symbole-256.png` | Symbole sur fond transparent |
| `png/logo-horizontal.png` | Symbole + nom, fond transparent (en-têtes, signatures, dossiers) |
| `png/logo-horizontal-fond-sombre.png` | Même chose pour fond sombre |
| `png/avatar-reseaux.png` | Photo de profil Instagram, Facebook, LinkedIn… (1080 × 1080) |
| `png/image-partage.png` | Image d'aperçu des liens (1200 × 630), identique à `docs/og.png` |

## Régénérer les images

Les PNG du site (`docs/icons/`, `docs/og.png`) et ceux de ce dossier sont dessinés par `export.html`.
Servez le dossier du projet avec un serveur qui accepte l'enregistrement des images, ouvrez
`logos/export.html` dans un navigateur et lancez `exporter()` dans la console.
